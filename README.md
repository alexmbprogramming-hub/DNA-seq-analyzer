# DNA-seq-analyzer
This is just a little project for my portfolio as Biologist and programmer

## Features
Now a days the project doesn't have any features yet, but the idea is to implement:
* Information about a DNA sequence:
  * Size of the sequence
  * C and G proportion vs A and T proportion
  * The complementary string
  * ...
 
## Before starting
Before starting using these files you have to know that is used the next libraries:
* streamlit -> For the interfaces
* pytest -> For the test of the application
These libraries has to be downloaded by the user in his own
